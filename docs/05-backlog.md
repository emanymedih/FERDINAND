## Альтернативные первые инструменты

| Направление | Минимальный сценарий | Входы | Проверяемый результат |
| --- | --- | --- | --- |
| Пятница | Расписание и поиск конфликтов | Один календарь, часовой пояс | Проверенная сводка без изменения событий |
| Рокфеллер | Импорт одной выписки | Один разрешённый файл, категории | Сверяемый реестр операций и расходов |
| КЗГ | Поиск пропущенных заявок | Письма и реестр | Отчёт со ссылками на источники |

## Общая готовность любого инструмента

Есть входной контракт, источник каждого значимого поля, режим прав, повторяемый результат, проверки ошибок, журнал, измеренная полезность и процедура восстановления. Запуск возможен из описанной среды без ручного восстановления неизвестных настроек.
