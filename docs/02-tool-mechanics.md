# Механика создания инструментов

Для каждого элемента ниже указано, как можно построить аналог в FERDINAND. Это проектная декомпозиция по доступным описаниям. Конкретную реализацию автора восстановить по PDF невозможно.

Общий цикл: получить данные, нормализовать, выделить намерение или поля, проверить, выполнить разрешённое действие, сохранить источник и вернуть результат. Подробности общей платформы находятся в [архитектуре](03-architecture.md).
