# Очередь разработки

Первой системой выбран **Фил**. Текущий этап — первая рабочая версия по [механикам](08-phil-mechanics.md): импорт справки Т-Банка, реестр и сводка реализованы и проверены на настоящем файле (код в `phil/`).

## Текущая очередь Фила

| ID | Задача | Условие завершения | Состояние |
| --- | --- | --- | --- |
| PHIL-001 | Личный контур выбран; уточнить перечень счетов | Учитываются только личные финансы пользователя; известны счета и границы отчёта | Открыто: пока один счёт Т-Банка |
| PHIL-002 | Выбрать формат и контрольную выписку | Есть разрешённый источник, валюта, период и ожидаемые остатки | Частично: формат — PDF «Справка о движении средств»; остатков в ней нет, сверка по итогам |
| PHIL-003 | Реализовать импорт и проверку повторов | Повтор файла и пересечение периодов обработаны; реальные одинаковые операции сохраняются | Готово: `phil/registry.py`, тесты |
| PHIL-004 | Проверить остатки и происхождение операций | Суммы сходятся; каждая запись раскрывается до источника | Частично: итоги сходятся до копейки, у записи есть страница и номер строки; остатки не проверяются |
| PHIL-005 | Добавить типы событий, категории и уточнения | Переводы, займы, возвраты и расходы различаются по подтверждённым условиям | Частично: тип операции по тексту определяет код; смысл переводов не уточнён |
| PHIL-006 | Сформировать первую сводку | Есть период, контур, свежесть данных и отдельная сумма спорных записей | Готово: `python -m phil summary` |
| PHIL-007 | Подключить регулярный запуск и канал доставки | Проверены разрешения, сбои, перезапуск и повторная доставка | Открыто |

## Альтернативные первые инструменты

| Направление | Минимальный сценарий | Входы | Проверяемый результат |
| --- | --- | --- | --- |
| Пятница | Расписание и поиск конфликтов | Один календарь, часовой пояс | Проверенная сводка без изменения событий |
| Рокфеллер | Импорт одной выписки | Один разрешённый файл, категории | Сверяемый реестр операций и расходов |
| КЗГ | Поиск пропущенных заявок | Письма и реестр | Отчёт со ссылками на источники |
| Выгода Авто | Уточнение правил торгов | Требования к участникам и ставкам | Спецификация аукциона для разработки |

## Общая готовность любого инструмента

Есть входной контракт, источник каждого значимого поля, режим прав, повторяемый результат, проверки ошибок, журнал, измеренная полезность и процедура восстановления. Запуск возможен из описанной среды без ручного восстановления неизвестных настроек.
