# Анкета для начала разработки

## Обязательные решения для первого инструмента

| Вопрос | Зачем нужен ответ | Текущий статус |
| --- | --- | --- |
| Какая система первая? | Определить результат первого выпуска | Выбран Фил, аналог Рокфеллера; только личные финансы |
| Какой конкретный процесс сейчас занимает время или теряет данные? | Выбрать измеримый эффект | Открыт |
| Где находятся данные и какие форматы доступны? | Выбрать коннектор или локальный импорт | Открыт |
| Каким результатом пользоваться ежедневно? | Определить отчёт, интерфейс и частоту | Открыт |
| Кто будет пользоваться инструментом? | Определить права и пользователей | Открыт |

## Решения до подключения внешних систем

Почтовый сервис, CRM или таблица; доступные экспорты; пример документа; место запуска; предпочтительный канал; допустимый бюджет; провайдер модели; политика хранения; часовой пояс; действия, требующие согласования; владелец процесса.

## Известные исходные условия

Пользователь хочет создать свои рабочие инструменты по аналогии с презентацией и вести результаты в FERDINAND. Первой системой выбран Фил, финансовый помощник по мотивам Рокфеллера. Пользователь выбрал только личные финансы и рассматривает Т-Банк как источник выписок. Конкретные счета, формат и регулярное получение пока уточняются. Презентация относится к продаже картонной упаковки; перенос этой отрасли на пользователя не предполагается.

## Короткий формат ответа

Первая система: ...
Процесс: ...
Источники: ...
Нужный результат: ...
Пользователи: ...

Для первой технической итерации достаточно ответов на эти пять пунктов. Остальные параметры уточняются перед зависимыми работами.
