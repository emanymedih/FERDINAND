# FERDINAND

Основа для разработки рабочих инструментов по мотивам презентации Павла для бизнес-клуба NOVA.

Приватный репозиторий: [emanymedih/FERDINAND](https://github.com/emanymedih/FERDINAND).

## Текущее состояние

Подготовлены каталог, механики, архитектура, контракты и задания на разработку. Первая рабочая версия Фила (FIN-01) в разработке; остальные инструменты имеют статус `planned`. Исходный код системы автора не предоставлен.

Первой системой выбран **Фил**, финансовый помощник по мотивам Рокфеллера, который ведёт **только личные финансы**. Работает импорт PDF-справки Т-Банка о движении средств в реестр операций и сводка за период ([подробности](docs/09-phil-tbank-statements.md)):

```
python3 -m pip install pdfplumber
python3 -m phil import data/<справка>.pdf
python3 -m phil summary --out data/сводка.md
python3 -m unittest
```

Реальные выписки и реестр лежат в `data/`, эта папка исключена из Git. Следующий шаг — уточнение смысла переводов и категорий; регулярное получение выписок ещё не настроено.

На дату 13 октября 2026 года каталог содержит **44 элементов**: 26 бизнес-инструментов, 6 инфраструктурных компонентов, 11 названий разделов со скриншота и 1 будущее направление.

## Системы из презентации

| Система | Назначение |
| --- | --- |
| Пятница | Личный ассистент: услуги, еда, поиск, календарь, наблюдения за здоровьем |
| Рокфеллер; в FERDINAND — Фил | Финансовый помощник: выписки, расходы, доходы, обязательства, сценарии |
| КЗГ | Рабочая платформа компании: заявки, документы, CRM, цены, долги, производство и маркетинг |
| Выгода Авто | Отдельная площадка-аукцион подержанных автомобилей |

## Правила разработки

Модель помогает разбирать текст, планировать и объяснять. Расчёты, права доступа, повторная обработка и журнал событий закрепляются за обычным кодом. Изменения внешних систем выполняются в пределах выбранного режима и согласованных доступов. Отрасль упаковки относится к исходному кейсу; отрасль пользователя пока уточняется.

Секреты, выписки и реальные клиентские данные хранятся вне Git. Удалённый репозиторий имеет приватную видимость; публикация исходных материалов требует отдельного решения.
