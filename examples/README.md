# Синтетические примеры

task.json, lead.json и result.json показывают предлагаемые контракты. Все данные демонстрационные. Они не относятся к реальному клиенту, подключённой почте или выполненной задаче. Числа в metrics относятся только к синтетическому примеру.

Схемы задают структуру данных. Проверка прав, происхождения каждого поля, уникальности, исполнения и согласования выполняется приложением и требует отдельной реализации.
