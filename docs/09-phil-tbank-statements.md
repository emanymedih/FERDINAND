# Фил: получение выписок для личных финансов

## Зафиксированный контур

Пользователь выбрал только личные финансы. Источник операций — личный счёт Т-Банка; первым форматом выбрана PDF-справка о движении средств. Периодичность обновления пока уточняется. Банковские и почтовые интеграции не подключены; вход в банк от имени пользователя не выполняется.

Вход на сайт банка для первого импорта не требуется: пользователь может предоставить выгруженный файл. Разбор и проверка полученного файла выполняются независимо от авторизации в банке.

## Варианты получения

| Вариант | Участие пользователя | Действия Фила | Состояние |
| --- | --- | --- | --- |
| Файл из приложения или личного кабинета | Получить документ и передать файл | Импортировать операции, проверить остатки и повторы, создать сводку | Предлагается для первой версии |
| Документы, поступающие на почту | Предоставить доступ к выбранному источнику писем и определить нужные документы | Обработать подходящие вложения, проверить покрытие периода и источники | Будущий способ; требует проверки фактических писем |
| Получение через браузер банка | Пройти защищённый вход и подтверждения банка | Скачать только согласованный документ за указанный период | Отдельный сценарий; может требовать повторной авторизации |
| Официальная интеграция для личных счетов | Подтвердить доступность подходящего продукта и порядок доступа | Получать операции через разрешённый интерфейс | Возможность для данного личного сценария пока не подтверждена |

## Что подтверждено официальными материалами Т-Банка

Справка банка описывает получение выписки в приложении или личном кабинете: выбрать счёт карты, открыть «Детали счета», затем «Выписка по счету» и нужный месяц.

В разделе банковских справок описана справка с движением средств и получение заказанных справок на электронную почту. Сам факт получения справки по почте не устанавливает автоматическую ежедневную доставку полного набора операций. Содержание и полнота конкретного файла проверяются после получения.

В документации T-API начало работы связано с ООО или ИП и доступом в личный кабинет Т-Бизнеса; метод выписки содержит права на операции компании. Этот бизнес-метод не принят как готовый способ подключения личных карточных счетов Фила. Вывод относится к проверенной документации; наличие иных партнёрских или специализированных продуктов требует отдельной проверки.

Формат первой реальной выгрузки определит адаптер импорта. Возможность CSV или XLSX для конкретного личного счёта пока не подтверждена. Для предоставленного PDF потребуется разбор текста; для скана — распознавание и дополнительная проверка.

## Проверенный формат: «Справка о движении средств» (PDF)

Пользователь предоставил 13 октября 2026 года справку по личному счёту за год. По ней реализован первый адаптер `phil/tbank_pdf.py`. Сама справка хранится только в `data/` и в Git не попадает.

Что есть в файле:

- шапка: номер справки и дата, ФИО, номер договора, номер лицевого счёта, период;
- таблица из шести колонок: дата и время операции, дата и время списания, сумма в валюте операции, сумма в валюте карты, описание, последние четыре цифры карты (у плат банку и кэшбэка вместо номера стоит «—»);
- заголовок таблицы повторяется на каждой странице, описание операции занимает несколько строк;
- в конце итоги «Пополнения» и «Расходы».

Чего в файле нет: начального и конечного остатков, банковского идентификатора операции и признака ожидающей операции. Поэтому полнота проверяется по итогам: импорт принимается, только если сумма поступлений и сумма списаний совпадают с итогами справки до копейки. Повторы определяются по SHA-256 файла и по отпечатку операции (см. `phil/registry.py`).

Результат на настоящем файле: 722 операции, итоги совпали, все описания распознаны по типам. Тип операции (покупка, перевод на договор, перевод по телефону, плата банку и т. д.) определяет код по тексту; экономический смысл переводов он не устанавливает.

Как пользоваться:

```
python3 -m phil import data/<справка>.pdf
python3 -m phil summary --from 2026-09-01 --to 2026-09-30
python3 -m phil counterparties          # получатели переводов без отметки, по сумме
python3 -m phil label 4373 own          # свой счёт владельца выписки
python3 -m phil label +7900... external --note "аренда"
```

Решение пользователя от 13 октября 2026 года: переводы между счетами владельца выписки считаются перемещением денег внутри одного человека, а не доходом или расходом. Свой ли это счёт, отмечает пользователь по реквизиту (договор, телефон, счёт, карта); отметка действует на все операции с этим реквизитом, прежние отметки сохраняются в истории. Переводы себе, копилка и вклады считаются своими по самой записи. Сводка делит движение на три потока: внешние доходы и расходы, перемещения между своими счетами и неуточнённые; строка «Всего по счёту» совпадает с итогами справки.

## Предлагаемый первый запуск

1. Пользователь получает документ по одному личному счёту за согласованный период.
2. Передаёт файл для разбора. В будущем его может принимать интерфейс Фила, например Telegram.
3. Проверяется состав документа: период, валюта, операции, начальный и конечный остатки.
4. Операции импортируются в реестр с указателями на источник и проверкой повторов.
5. Суммы сверяются, неизвестные назначения попадают в очередь уточнений.
6. Пользователь получает отчёт с границами полноты и датой актуальности.

Начальный период и счёт предлагается выбрать до разработки конкретного адаптера. Один полный месяц может дать достаточно примеров для первичной проверки, если выгрузка содержит нужные поля; это проектное предложение.

## Переход к регулярному получению

После проверки файла выбирается частота обновления. Если подходящие документы уже поступают по почте, исследуется обработка этих писем с ограниченным доступом. Если требуется регулярное скачивание из банка, отдельно проверяются доступность интерфейса, подтверждения и восстановление после завершения сессии. Браузерный сценарий не считается гарантированно автономным.

Фил получает документы в пределах согласованного доступа. Пароли и подтверждения банка вводятся пользователем через предназначенный защищённый механизм. Реальные выписки, операции и секреты остаются вне Git; в репозитории находятся код, спецификации и синтетические примеры.
