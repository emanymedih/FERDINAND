# Фил: выписка Сбера и переводы между своими счетами

## Что реализовано

13 октября 2026 года пользователь предоставил выписку СберБанка по второму личному счёту того же владельца. Фил научился:

1. Читать PDF «Выписка по платёжному счёту» СберБанка (`phil/sber_pdf.py`).
2. Хранить несколько счетов разных банков в одном реестре.
3. Находить переводы между своими счетами в разных банках (`phil/transfers.py`) и не считать их доходом или расходом.

Банк определяется по первой странице файла, команда загрузки одна:

```
python3 -m phil import data/справка-тбанк.pdf data/выписка-сбер.pdf
python3 -m phil transfers
python3 -m phil summary --from 2026-09-01 --to 2026-09-30
```

## Формат выписки Сбера

Факты по предоставленному файлу:

- шапка: владелец, номер счёта, привязанные карты, валюта, период;
- итоги: остаток на начало, «Пополнение», «Списание», остаток на конец;
- операция занимает две строки: (1) дата, время МСК, категория банка, сумма в валюте счёта, остаток после операции; (2) дата обработки, код авторизации, описание;
- поступления помечены «+», списания идут без знака; операции идут от новых к старым.

Проверка полноты строже, чем у Т-Банка: импорт принимается, только если сходятся итоги поступлений и списаний, начальный остаток плюс операции равен конечному, а остаток после каждой операции совпадает с расчётным. Потерянная или неверно прочитанная строка не пройдёт ни одну из трёх проверок.

Тип операции определяется по категории и описанию: «Заработная плата» и «Аванс по заработной плате» — зарплата (внешний доход); «Перевод СБП» — перевод по СБП; «Операция по карте» — покупка. Сумма в валюте операции для валютных покупок пока сохраняется только в предупреждении — в предоставленном файле таких операций нет.

## Сопоставление переводов

Пара создаётся, если одновременно выполнено:

- списание и поступление на **разных** счетах;
- у обоих счетов **один владелец** по данным выписок;
- суммы равны, валюта одна;
- время отличается не больше чем на 10 минут;
- пара **однозначна**: у списания один подходящий кандидат, и у поступления тоже.

Неоднозначные случаи не угадываются: Фил выводит их при загрузке для ручного разбора. Повторный запуск не создаёт дублей.

Результат на настоящих файлах: найдены две пары, обе с разницей 0 минут — поступления зарплаты в Сбер, переведённые по СБП в Т-Банк. Зарплата учитывается один раз, как доход в Сбере; пополнения Т-Банка на те же суммы — перемещение между своими счетами. Суммы и даты настоящих операций в репозиторий не записываются, так как он публичный.

## Ограничения

- Время в справке Т-Банка не подписано часовым поясом. Совпадение до минуты с выпиской Сбера (МСК) показывает, что это московское время.
- Переводы, которые банки проводят дольше 10 минут (обычный межбанковский перевод по реквизитам), пока не сопоставляются автоматически.
- Сводка показывает покрытие периода по каждому счёту: если выписка счёта начинается позже запрошенного периода, это видно в строке «нет данных до …».
